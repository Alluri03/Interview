# Two short coding exercises (React & FastAPI)

Each exercise is designed to be solvable in ~15–20 minutes.

## 1) react-userlist-exercise
- `npm install && npm run dev`
- Implement debounced search, pagination (5/page), and highlighting in `src/App.jsx`.
- `npm test` to run checks.

## 2) fastapi-tasks-exercise
- `pip install -r requirements.txt`
- Implement TODOs in `app/main.py` for duplicates, pagination filter, and toggle.
- `pytest` to run checks.

### Scoring rubric (quick)
- **Correctness (50%)**: All tests pass.
- **Code quality (30%)**: Clear, idiomatic, small functions/components.
- **Time/approach (20%)**: Reasonable trade-offs, sensible naming, basic error handling.
